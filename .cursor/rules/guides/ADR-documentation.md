## Структура файлов и папок

- `docs/adr/` — хранение документов архитектурных решений (ADR)
- `docs/infrastructure/` — хранение технических руководств по инфраструктуре
- `docs/README.md` — оглавление со ссылками на все документы

## Формат наименования ADR

- Использовать сквозную нумерацию `0001`, `0002`, `0003`
- Разделитель элементов — дефис
- Символы — нижний регистр латиницы
- Пример — `0002-redis-bullmq-queues.md`
