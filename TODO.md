# Интегрировал в бэкенд Spectral lint - утилита для контроля сырого openApi
Spectral анализирует не сам код бэкенда и не его реальное поведение в рантайме. Он проверяет статический файл спецификации OpenAPI в формате YAML или JSON.

Инструмент гарантирует, что в самом файле спецификации описаны обязательные коды ошибок вроде 404, а также стандарты путей и параметров. Он не проверяет, написан ли реальный код бэкенда так, чтобы этот код состояния возвращался на самом деле. За проверку фактического поведения отвечают интеграционные тесты.

Размещать Spectral целесообразно там, где файл спецификации фиксируется или генерируется в CI, перед тем как этот файл забирает фронтенд.


Можно вставить в тикет как есть. Если нужно — отдельным абзацем добавлю рекомендуемый allowlist для `sanitize-html` конфигом.
